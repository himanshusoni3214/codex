# Structured Data Coverage

All JSON-LD is rendered via `resources/views/partials/structured-data.blade.php` and generated by `app/Services/StructuredDataService.php`.

## Route Coverage

- Site-wide (`*`): `Organization`, `WebSite`
- Contact + Local pages (`/contact`, `/toronto-gemstone-store`, `/canada/{province}`): `JewelryStore` (LocalBusiness)
- Pages with visible breadcrumb UI: `BreadcrumbList`
- Product detail pages (`/gemstones/{typeSlug}/{productSlug}`): `Product` + `BreadcrumbList` + `FAQPage` (when product FAQs are visible)
- FAQ page (`/faq`): `FAQPage`

## Example Product JSON-LD

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "BKK Big Blue Sapphire 101",
  "image": ["https://naturalgem.com/images/gemstones/example.webp"],
  "description": "Certified sapphire with transparent disclosure.",
  "sku": "101",
  "brand": {
    "@type": "Brand",
    "name": "Natural Gem Store"
  },
  "offers": {
    "@type": "Offer",
    "price": "4500.00",
    "priceCurrency": "CAD",
    "availability": "https://schema.org/InStock",
    "url": "https://naturalgem.com/gemstones/sapphire/bkk-big-blue-sapphire-101"
  }
}
```

## Validation Flow

1. Open [Google Rich Results Test](https://search.google.com/test/rich-results).
2. Test:
   - `https://naturalgem.com/gemstones/{type}/{product}`
   - `https://naturalgem.com/contact`
   - `https://naturalgem.com/faq`
3. Fix any **critical** errors first.
4. Keep schema aligned with visible content (especially FAQ, pricing, availability).
